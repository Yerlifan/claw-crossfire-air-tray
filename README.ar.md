# Claw CrossFire AIR: التحكم من شريط النظام

🇹🇷 [Türkçe](README.tr.md) · 🇬🇧 [English](README.md) · 🇪🇸 [Español](README.es.md) · 🇫🇷 [Français](README.fr.md) · 🇩🇪 [Deutsch](README.de.md) · 🇷🇺 [Русский](README.ru.md) · 🇨🇳 [中文](README.zh.md) · 🇯🇵 [日本語](README.ja.md) · 🇰🇷 [한국어](README.ko.md) · 🇸🇦 **العربية**

تطبيق صغير في شريط النظام للفأرة اللاسلكية **Claw CrossFire AIR V1**. لا يحتاج إلى برنامج الشركة المصنّعة ولا إلى ملف DLL الخاص به، بل يتواصل مع الفأرة مباشرة عبر USB HID. يعمل على Windows، ودعم Linux في مرحلة تجريبية.

![قائمة شريط النظام](docs/screenshot.png)

## الميزات

| | |
|---|---|
| **البطارية** | النسبة المئوية برقم كبير في شريط النظام، وإطار أصفر أثناء الشحن. إشعارات عند بدء الشحن وانتهائه، وعند امتلاء البطارية، وعند 20% و10%. تعرض الأيقونة `II` عندما تكون الفأرة في وضع السكون، وتختفي عندما لا تكون الفأرة متصلة. |
| **كل الإعدادات في قائمة النقر الأيمن** | مستويات DPI (القيم، المستوى النشط، عدد المستويات)، معدل الاستجابة، منع الارتداد، مزامنة الحركة، تصحيح الزاوية، التحكم في التموج، الأداء الأقصى، وضع الإضاءة ولونها وسطوعها وسرعتها، إطفاء الإضاءة أثناء الحركة، مهلة الإطفاء، مؤشر DPI، وضع المدى البعيد. كل عملية كتابة تُقرأ من الفأرة مجدداً ويتم التحقق منها. |
| **خمسة إعدادات مسبقة قابلة للتعديل** | ألعاب، سطح المكتب، دقة، توفير البطارية، عرض تقديمي. تطبيق بنقرة واحدة، حفظ إعدادات الفأرة الحالية في الإعداد المسبق، إعادة التسمية، استعادة الافتراضي. تُحفظ في `config.json`. |
| **المساعدة** | تعرض القائمة الفرعية للمساعدة كل إعداد؛ وبالنقر عليه يظهر شرح قصير كإشعار. "فتح الدليل" يعرض كل الشروح في نافذة قابلة للتمرير. |
| **عشر لغات** | Türkçe، English، Español، Français، Deutsch، Русский، 中文، 日本語، 한국어، العربية. يتبع لغة النظام ويمكن تغييره من القائمة، ويُحفظ الاختيار. |
| **خفيف** | أيقونة واحدة في شريط النظام، بلا خدمة ولا برنامج تشغيل، ولا يكتب شيئاً خارج مجلده باستثناء `config.json`. يمكن تشغيله مع بدء Windows. |

> لا علاقة له بالشركة المصنّعة. تم استخراج البروتوكول بالهندسة العكسية من خلال مراقبة برنامج الشركة، واختُبر فقط على **CrossFire AIR V1** (PixArt PAW3325، البرنامج الثابت v2.0، مستقبل 2.4 GHz). الاستخدام على مسؤوليتك.

## التثبيت

### الخيار A: ملف تنفيذي جاهز (لا يحتاج Python)

1. نزّل `ClawTray_<الإصدار>_win64.zip` من صفحة [Releases](https://github.com/Yerlifan/claw-crossfire-air-tray/releases) وفكّ ضغطه في أي مجلد.
2. شغّل `ClawTray.exe`. تظهر الأيقونة في شريط النظام (ربما تحت السهم `^`).
3. اختياري، اختصارات في قائمة ابدأ وسطح المكتب وبدء التشغيل:
   ```powershell
   powershell -ExecutionPolicy Bypass -File kurulum.ps1
   ```

قد يحذّر Windows SmartScreen في المرة الأولى لأن الملف غير موقّع؛ اختر *مزيد من المعلومات، تشغيل على أي حال* أو استخدم الخيار B.

### الخيار B: من الشيفرة المصدرية

المتطلبات: Windows 10/11 (أو Linux، انظر الخيار C)، Python 3.10 أو أحدث.

```powershell
git clone https://github.com/Yerlifan/claw-crossfire-air-tray.git
cd claw-crossfire-air-tray
pip install -r requirements.txt
pythonw claw_tray.py
```

لإزالة التثبيت: `kurulum.ps1 -Kaldir` ثم احذف المجلد. سطر الأوامر: `--status` يعرض الحالة، `--lang ar` يفرض اللغة، `--guide` يفتح الدليل.

### الخيار C: Linux (تجريبي، لم يُختبر بعد على عتاد حقيقي)

الفأرة نفسها لا تحتاج إلى برنامج تشغيل على Linux؛ هذا التطبيق يضيف فقط واجهة البطارية والإعدادات في شريط النظام. لم يتسنَّ التحقق من نسخة Linux إلا في آلة افتراضية بدون توصيل الفأرة؛ التقارير من عتاد حقيقي مرحّب بها.

```bash
./linux/kurulum.sh        # قاعدة udev (sudo)، حزم pip، ملف .desktop + بدء تلقائي
```

حزم Debian/Ubuntu: `sudo apt install python3-gi gir1.2-ayatanaappindicator3-0.1 python3-tk`؛ وفي GNOME فعّل أيضاً إضافة *AppIndicator*. للإزالة: `./linux/kurulum.sh -u`.

## من المفيد معرفته

- **لا يعمل بالتزامن مع برنامج CrossFire.** إذا تواصل الاثنان مع الفأرة في الوقت نفسه ينهار CrossFire (الفأرة لا تتأثر)؛ لذا يوقف التطبيق نفسه مؤقتاً ما دام CrossFire يعمل (الأيقونة `!`). يمكنك إزالة CrossFire؛ فالتطبيق لا يعتمد عليه.
- لا يمكن كتابة الإعدادات عندما تكون الفأرة في وضع السكون (نحو دقيقة بلا حركة): تعرض الأيقونة `II` وتعود فور تحريك الفأرة.
- إذا حدث خطأ ما، فإن *Restore* في برنامج الشركة يعيد الفأرة إلى إعدادات المصنع.
- الماكرو وإعادة تعيين الأزرار خارج النطاق عمداً.
