# Claw CrossFire AIR: управление из системного трея

🇹🇷 [Türkçe](README.tr.md) · 🇬🇧 [English](README.md) · 🇪🇸 [Español](README.es.md) · 🇫🇷 [Français](README.fr.md) · 🇩🇪 [Deutsch](README.de.md) · 🇷🇺 **Русский** · 🇨🇳 [中文](README.zh.md) · 🇯🇵 [日本語](README.ja.md) · 🇰🇷 [한국어](README.ko.md) · 🇸🇦 [العربية](README.ar.md)

Небольшое приложение в системном трее для беспроводной мыши **Claw CrossFire AIR V1**. Ему не нужны ни программа производителя, ни её DLL: оно общается с мышью напрямую по USB HID. Windows, поддержка Linux в бета версии.

![Меню в трее](docs/screenshot.png)

## Возможности

| | |
|---|---|
| **Батарея** | Крупный процент в трее, жёлтая рамка во время зарядки. Уведомления при начале и окончании зарядки, при полном заряде, а также при 20% и 10%. Пока мышь спит, значок показывает `II`; если мышь не подключена, значок скрывается. |
| **Все настройки в контекстном меню** | Уровни DPI (значения, активный уровень, число уровней), частота опроса, антидребезг, Motion Sync, выравнивание угла, контроль ряби, максимальная производительность, режим, цвет, яркость и скорость подсветки, гашение при движении, задержка выключения, индикатор DPI, режим дальней связи. Каждая запись перечитывается из мыши и проверяется. |
| **Пять редактируемых пресетов** | Игры, Рабочий стол, Точность, Экономия батареи, Презентация. Применение одним кликом, сохранение текущих настроек мыши в пресет, переименование, сброс. Хранятся в `config.json`. |
| **Справка** | Подменю Справка перечисляет все настройки; клик показывает краткое объяснение уведомлением. «Открыть руководство» показывает все объяснения в прокручиваемом окне. |
| **Десять языков** | Türkçe, English, Español, Français, Deutsch, Русский, 中文, 日本語, 한국어, العربية. Следует языку системы, переключается в меню; выбор запоминается. |
| **Лёгкое** | Один значок, без службы, без драйвера, ничего не пишет вне своей папки, кроме `config.json`. При желании запускается вместе с Windows. |

> Не связано с производителем. Протокол получен обратной разработкой путём наблюдения за программой производителя и проверен только на **CrossFire AIR V1** (PixArt PAW3325, прошивка v2.0, приёмник 2,4 ГГц). Используйте на свой риск.

## Установка

### Вариант A: готовый исполняемый файл (Python не нужен)

1. Скачайте `ClawTray_<версия>_win64.zip` со страницы [Releases](https://github.com/Yerlifan/claw-crossfire-air-tray/releases) и распакуйте в любую папку.
2. Запустите `ClawTray.exe`. Значок появится в трее (возможно, под стрелкой `^`).
3. По желанию, ярлыки в меню Пуск, на рабочем столе и в автозагрузке:
   ```powershell
   powershell -ExecutionPolicy Bypass -File kurulum.ps1
   ```

Windows SmartScreen может предупредить при первом запуске, так как файл не подписан; выберите *Подробнее, Выполнить в любом случае* или используйте вариант B.

### Вариант B: из исходного кода

Требования: Windows 10/11 (или Linux, см. вариант C), Python 3.10 или новее.

```powershell
git clone https://github.com/Yerlifan/claw-crossfire-air-tray.git
cd claw-crossfire-air-tray
pip install -r requirements.txt
pythonw claw_tray.py
```

Удаление: `kurulum.ps1 -Kaldir`, затем удалите папку. Командная строка: `--status` показывает состояние, `--lang ru` задаёт язык, `--guide` открывает руководство.

### Вариант C: Linux (бета, на реальном оборудовании ещё не проверено)

Самой мыши драйвер под Linux не нужен; приложение лишь добавляет интерфейс батареи и настроек в трее. Порт для Linux удалось проверить только в виртуальной машине без подключённой мыши; отзывы с реального оборудования приветствуются.

```bash
./linux/kurulum.sh        # правило udev (sudo), пакеты pip, .desktop + автозапуск
```

Пакеты Debian/Ubuntu: `sudo apt install python3-gi gir1.2-ayatanaappindicator3-0.1 python3-tk`; в GNOME дополнительно включите расширение *AppIndicator*. Удаление: `./linux/kurulum.sh -u`.

## Полезно знать

- **Не работает одновременно с программой CrossFire.** Если обе общаются с мышью одновременно, CrossFire падает (мышь не страдает); поэтому приложение ставит себя на паузу, пока запущен CrossFire (значок `!`). CrossFire можно удалить; приложение от него не зависит.
- Пока мышь спит (около минуты без движения), настройки записать нельзя: значок показывает `II` и восстанавливается, как только мышь подвигать.
- Если что то пошло не так, *Restore* в программе производителя возвращает заводские настройки.
- Макросы и переназначение кнопок намеренно не поддерживаются.
